# 参考匹配：先看用户要什么，再决定怎么做

## 观察顺序

1. 找出真正的单张幻灯片边界。手机截图、短视频灰底、上下拼接、“前后对比”标题、水印都不是 PPT 设计的一部分。
2. 比较多个参考，不把一张封面当作内容页模板。分别看数据、方法、机制、表格与收尾页。
3. 把稳定特征转换成规范：题头颜色/分量、摘要位置、横带作用、组数与比例、图下注解、强调词、边框、边距和有效密度。
4. 将已认可实际样页作为更直接的落地基准。如果其布局与早期文字方案不同，以用户最新认可的画面为准，保留内容正确性。

## 八类参考观察，可迁移的结构

以下是对实际科研答辩参考画面的结构提炼；不包含或再分发原始素材，不认可其具体科学内容。

- 团队/基础与成果参考：上下证据带组织不同层次，蓝条分组；表格有强蓝表头、浅灰隔行，表下再放证据。迁移分组，不复制人物、证书、单位或成果。
- 工艺/演化参考：两行前置摘要，蓝色命题带，主体可为三组，或左约 2/3 大证据加右约 1/3 深入解释。迁移层级，不复制显微图或实验事实。
- 课题分解/研究内容参考：总任务横梁加下属任务；三列可中央略宽；双模块内部再分图、说明、限制。迁移共同字段，不把所有页变成四张空标题卡。
- 背景/现状参考：问题证据在左，窄过程轴居中，机制解释在右；三组比较可有标题、图、区别、限制四层。参考中不同学科文字与图有不一致，说明视觉参考不能作为科学来源。
- 三段工艺前后对照：松散正文改成两行摘要、共用逻辑带、三组方法证据与逐图解释。成功不是“图多”，而是文字与证据相邻且逻辑清楚。
- 双模块前后对照：公共前提与主线之下，两个证据组各自有图和结论。无需为了“高级感”取消模块框。
- 三列现状前后对照：蓝色圆角组头和底部淡蓝限制带形成共同阅读字段。三列必须有真实比较关系，不能从无关学科借图凑密度。
- 问题—过程—解释前后对照：中央窄轴承担过程连接，底部有具体落点。没有真实顺序时，不照搬向下箭头。

## 什么算真正匹配

把新页与用户参考或认可样页并排看，不只比较色值：

- 第一眼的题头分量、蓝白结构和文字密度是否同类？
- 上方是否前置命题/问题，主体是否有可追踪的证据组？
- 图下注解是否紧贴证据，还是又变成远处松散旁注？
- 红色是否点出对象、差异或限制，还是无依据地强调“领先/可靠/突破”？
- 模块和图表有足够内部层次，还是仅给原来空疏页面加了蓝框？

不要为了迎合参考牺牲科学。高质量大图页不必强行三栏，可信的原生表格也不必换成照片。明确参考允许密集，就不默认追求大留白；参考要求克制，也不机械复制本包的蓝白密集样式示例。

## 授权与版本

仅借版式语言，不复制参考的 Logo、人物、机构名称、专有素材或结论。实际使用外部素材仍须核查来源与使用条件。

最新明确反馈取代早先冲突偏好或限制。用户已认可方向并要求完成剩余页时，应继续落实该方向，不把已经解决的视觉选择重复抛回用户，也不能把获准的几页误报成整稿完成。

## 当新反馈要求像科学机制样页那样图像化

进一步核对实体、镜头、材质和过程标注，而不只保留蓝色边框。真实感的目标是让对象解释机制，不能转成商业 3D 图标或在原长段落上方加小图。最新认可的实体场景优先于旧的文字分组方案，但真实数据与精确抽象定义不因此被替换。用户选择去掉小页脚时，执行来源迁移，不把旧参考中的小字自动恢复。

## 当用户提出“像 NotebookLM 一样”

把要求转成来源驱动的讲述和视觉解释，不猜测特定产品的内部流程。先核对材料论证，再按主关系安排场景、图表或原生结构。蓝白红与密度可保留，但不沿用整稿同一个“顶带 + 三面板 + 结论条”骨架。普通主题标题、铺垫页和精确表格仍有合理位置；缺少真正承担解释的插画时主动生成，而不是给每页添装饰小图。详见 [来源驱动视觉叙事](source-grounded-storytelling.md)。
