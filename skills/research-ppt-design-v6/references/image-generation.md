# 受控生图：先定科学任务，再生成对象

## 边界

可生成非定量研究对象、材料剖面、教学场景和封面背景。不能生成或修补成看似真实的数据曲线、遥感/显微结果、定量地图、热图、预测结果或证据截图。

真实感不是数据真实性。生成图只能解释已核对的过程，不成为新增科学结论的依据。

## 按视觉缺口主动补图

先读材料和逐页讲述任务。缺少能解释实体、接口或过程的非定量插画时，直接补足适用场景，不停在“建议配图”或占位框；详见 [缺图闭环](source-grounded-storytelling.md#缺图闭环)。能用准确原生图表达的定义或控制条件无需生图。

如果缺少的是实测、模型或统计证据，仅在当前任务允许的研究范围内找合法且匹配的真实来源；仅依据给定材料的任务直接说明缺口，不擅自扩展研究内容。找不到时不能生成相似外观的结果。工具不可用或结果不可靠时可用清楚标明的原生概念示意，不能声称已经获得真实图片或通过验证。

## 先写对象规格

页面用途 + 来源支持的对象及形态 + 连续空间/物理接口 + 主关系和可见锚点 + 视角/画幅 + 光照材质 + 留给原生标注的位置 + 禁止项。生成主图而不是整页 PPT；不要让工具在图中写结论、坐标、刻度或段落。

原创提示示例：

“用于蓝白科研演示的非定量流域机制场景。一个连续山地到下游的三分之四剖面：上游可辨认降雨、水库及连接河道、下游湿地、灌溉田和居住地，出口有清楚的调节结构。水面水平、河道连通、地形合理，土壤剖面与植被相连。白底，柔和统一方向日光，克制真实材质，周围保留给原生标签和引线的空间。不画文字、数字、箭头、图表、地图刻度、Logo。不代表实际地点、工程设计或计算结果。”

仅在当前材料支持这些实体与关系时使用，不把此场景变成所有学科通用背景。

## 连贯性

- 一组比较使用同类镜头、光线、材质、边缘处理与合理尺度。不要混合产品图标、实景摄影、游戏资产和科学剖面。
- 三维感用于表达实体，不使用霓虹、漂浮光环、虚拟大脑或发光数据立方体制造科技感。
- 生成后先独立看主关系是否可辨，再看物理形态：水面、河流、根系、土壤、雪冰、设施是否合理。连错水管、漂浮传感器不能由后加标签解释成正确。
- 分组有意义时可用多个匹配对象；关系连续时优先一个连贯场景，不拼三个无关块。

## 原生叠加与语义锚点

中文、栏头、过程名、数值、引线、箭头和来源另做原生对象。图像只承担外观与空间，不绘整页 PPT。给标签预留空间，文字不压忙乱纹理，也不依靠白色图片矩形遮住粗糙裁切。

标签锚点应是实际可见特征：降水对应雨线，储水对应水体，土壤对应剖面，管理对应控制点。原生网格可以覆盖模型地域，不能用虚假彩色场冒充模型输出。检查小切片残影、重复轮廓、白边、漂浮碎块和对齐错位。

未给数值的面积、箭头宽度、液滴数量和地形不能暗示测量；若尺度夸张，说明为示意。正负反馈、物质和能量交换分别核对，不给每条接口机械写相同通量。

## 来源与示意身份

完整记录生成用途及非数据性质。按当前任务规范正常可读地呈现来源。只有当前任务明确选择去掉微小页脚时，才将完整记录迁移到逐页备注和可读末尾来源页，不以挪位置的方式再次添加小字。

必要的正常字号“机制示意”可放在逻辑带、组头或图边，重要科学限定仍可见。移走页脚不是许可把生成场景描述为真实观测或已验证模型。

## 素材效率

按实际显示面积选择像素。连续色调可合理压 JPEG，透明对象可用 PNG，精确网格与连接优先原生。逐张检查细节和合成边缘，不用统一低质量压缩。

默认无体积上限。清理重复媒体与无用背景即可；有当前明确预算才按预算优化，不从旧版本自动继承上限，不牺牲轴标或证据清晰度。
