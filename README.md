# 科研 PPT 设计 Skill

一个面向研究生开题、组会和答辩的中文设计工作流，帮助 AI 或制作者把研究问题、方法和证据组织成可讲述、可核验的演示文稿。

它适合整理内容、制定视觉方向、审查页面和交接制作规格。它本身不是 PowerPoint 插件，也不会仅凭安装就自动生成或验证 PPT 文件。实际制作能力取决于使用它的 AI 工具、演示软件及已提供的研究材料。

## 快速使用

1. 获取本仓库中的完整 `skills/research-ppt-design-v6/` 目录，保留 `SKILL.md` 以及它引用的子目录；不要只复制首页说明。
2. 在支持本地技能的 AI 工具中安装，或把完整目录交给能读取文件的 AI，明确要求先阅读 `SKILL.md`。
3. 提供听众、场景、时长、研究问题、可用证据、模板要求和期望输出。可以参考 [示例任务](examples/example-brief.md)。
4. 明确请求“设计方案”“修改建议”或“制作文件”，并说明是否需要先确认代表页。

### 在 Codex 中按项目安装

在你的项目中建立下面的目录，将完整 skill 内容放入其中，确保 `SKILL.md` 位于所示位置：

```text
你的项目/
└── .agents/
    └── skills/
        └── research-ppt-design-v6/
            ├── SKILL.md
            └── 其余随包文件与子目录
```

把 `skills/research-ppt-design-v6/` 复制到上述位置，避免多套一层同名目录。然后在 Codex 的项目会话中使用 `$research-ppt-design-v6`，附上任务与材料。Codex 会自动发现本地技能变更；若未显示，可重启 Codex。其他工具的安装位置和触发方式以各自说明为准。位置与调用方式依据 [OpenAI 官方技能文档](https://developers.openai.com/codex/build-skills)。

## 输入与交付

建议输入包括：听众及其已有知识、汇报目标与时长、真实研究内容与数据、可以使用的文献和图件、学校或课题组模板、编辑软件、页面比例，以及需要交付的格式。

可请求的输出包括内容结构、逐页主张与证据表、视觉方向、代表页制作规格、审查建议和制作交接说明。可编辑文件及预览只有在实际工具支持、材料充分且完成相应验证时才应声明交付。

## 依赖与局限

- 阅读设计工作流需要能够读取 Markdown 文件的 AI 或编辑器。
- 辅助检查脚本使用 Python 3 标准库，不需要安装 pip 包；本次测试环境为 Windows / Python 3.11.15，未测试其他 Python 版本。脚本只读 PPTX，不会修改或压缩演示文稿。
- 实际 PPT 制作、渲染、字体和图片处理可能需要另行准备相应软件与素材；辅助脚本不代表完整的 PPT 排版或渲染工具。
- AI 输出可能出现误读或错误，研究结论、数值、引用和最终版式仍需人工核验。不得用虚构数据补齐研究缺口，也不得把概念插画当作实验或观测结果。
- 本项目只发布可复用的设计方法、文档和原创辅助脚本，不附原始科研 PPT、书籍 PDF、私人页面截图或用户对话。实际使用的论文图、字体和其他素材需由使用者核对相应使用条件。

## 检查 PPTX 结构与体积

在仓库根目录运行（如你的环境使用 `python3`，请替换命令中的 `python`）：

```bash
python skills/research-ppt-design-v6/scripts/check_pptx.py "your-talk.pptx"
python skills/research-ppt-design-v6/scripts/check_pptx.py "your-talk.pptx" --json
```

只有存在明确的文件大小要求时，才传入以字节为单位的上限。例如明确要求 10 MiB 时：

```bash
python skills/research-ppt-design-v6/scripts/check_pptx.py "your-talk.pptx" --max-bytes 10485760 --json
```

默认没有大小上限。脚本检查 ZIP CRC、必需部件和已声明的内部关系目标，并报告幻灯片部件数量、原生文字及图形对象数量、媒体压缩体积和嵌入文件等信息。退出码 `0` 表示所做的有限结构检查及可选体积检查通过，`1` 表示发现结构问题或超过指定预算，`2` 表示参数、文件读取或解析错误。告警可以与退出码 `0` 同时出现，仍需按实际任务审查。

结构通过不能证明科学正确、排版美观、文字可读、所有内容可编辑，或在 PowerPoint 中显示正常。脚本按 ZIP 中 `slideN.xml` 的文件名统计幻灯片部件，不核对演示文稿实际的引用列表和播放顺序；`[Content_Types].xml` 及 `presentation.xml` 只检查存在，不校验其中内容。交付前仍需逐页渲染、检查裁切和遮挡、核对数据与引用，并在目标软件中验证。脚本不渲染页面，不检测所有 OOXML 合规性，也不自动压缩文件。

本次运行了 23 项自制最小 PPTX 测试，全部通过；27 次命令行运行均验证输入内容、修改时间与目录文件集不变。测试覆盖正常结构、可选大小限制、缺失部件或关系目标、告警和读取 / 解析错误。合成测试文件用于检查脚本行为，不是已通过 PowerPoint 渲染验收的演示文稿示例。

可在仓库根目录运行 `python tests/test_check_pptx.py` 复现；详见 [测试记录](docs/validation.md)。
