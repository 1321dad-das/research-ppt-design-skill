# 科研 PPT：从来源到视觉叙事

“像 NotebookLM 一样”的目标是从材料讲清楚对象、关系和证据，形成连贯且有视觉解释力的科研汇报，不是照搬产品界面、生成整页图片或给所有页面套同一种卡片。按当前任务选择的样式档案执行；用户选择皇家蓝、白底、少量红色强调及科研密度时，保留这一语言。美化不能改变科学含义。

## 1. 锁定最新范围与参考

- 区分制作、修改、审查、模板与 skill，只做当前请求；最新明确要求取代早期冲突限制。实际查看参考和已有页面，认可样页比抽象风格词更有用。
- 保留旧版，新建当前版本。确认材料、页数/范围、听众、时长、编辑要求和交付格式。参考中的三联结构不是每页必须三栏。
- 默认无文件大小上限；仅按当前任务明确要求设置预算。优化重复媒体，不牺牲证据清晰度。
- 采用当前任务明确选择的样式和来源规范，不从旧稿或案例继承用户偏好。未明确要求简化时，保留正常可读的来源和必要生成示意说明。只有当前任务明确选择去掉微小页脚时，才把完整记录迁移到逐页备注和正常可读的末尾来源页；页码、重要条件和许可要求的署名仍保留。

## 2. 先从材料组织故事，再选择布局

读 [来源驱动视觉叙事](references/source-grounded-storytelling.md)。先为每页确定讲述任务、来源支持、必须保留的条件、主关系和视觉职责，再决定版式。

- 讲述任务可以是背景、问题、对象、方法、证据、比较、解释或边界，不强迫每页作新结论。
- 背景和定义页可用普通主题标题；只有证据支持时才写结论标题。不能为了“有力度”把相关写成因果，把条件性推断写成事实。
- 空间关系用剖面/位置；交换或机制用连续系统；共同字段用对照；定量结果用真实图表；抽象定义和控制条件用原生表格/图解。
- 页面家族由内容关系决定。相邻受控比较可复用结构，但不把整稿固定为“摘要 + 三卡片 + 底部结论带”。

## 3. 区分解释场景、数据证据和精确表格

读 [语义文字到场景](references/semantic-scene-workflow.md)，需要具体例子时看 [场景案例](references/scene-cases.md)。

- 空间、储存、交换、物理过程和地方应用：用足够大的科学对象、连续剖面或同场景比较承担解释。
- 曲线、地图、实验图片和模型输出：保留真实证据；缺失数据图不能靠生图补成结果。
- 概率定义、集合控制条件、正式比较表和文献表：优先准确的原生文字、表格和关系图，不强加插画。
- 混合页：场景说明实体与空间，原生对象表达过程、数值、条件、定义和决策标准。

## 4. 缺图就补，先补理解而不是装饰

按 [受控生图](references/image-generation.md) 盘点视觉缺口。能帮助理解且没有适用素材的非定量对象/机制场景，主动生成；不因缺少“好看的图”给表格或证据页硬加图片。工具不可用或生成失败时，继续采用准确原生示意并说明缺口，不能把草稿冒充完成。

每个视觉建立“命题 → 来源 → 可见实体/界面 → 关系 → 原生标签锚点 → 不可删条件”的映射。规划构图、视角、光照和标注留白；生成后先看物理关系，再叠原生标签。必要时修订图像，不能靠箭头挽救断开的水系或不存在的控制点。

图像移走若不影响理解，很可能只是装饰。不要保留原段落不动，再在上方贴缩略图；应把可定位对象变为就地标签，把过程变为有含义的连接，把必要抽象条件保留为清楚文字。

## 5. 保持科研密度与可编辑性

按 [参考匹配](references/reference-matching.md) 统一字体、色彩、边距及信息层级，而非统一每页骨架。[蓝白密度系统](references/dense-layout-system.md) 是可选样式档案，仅在当前任务选择这一方向时使用。

- 主图大到能看见需讲解的结构，证据和解释相邻。密度来自有效关系、共同字段和清楚标签，不来自小字、框线数量或堆素材。
- 标题、标签、箭头、表格、关键数值和科学限定保持原生可编辑；真实证据可保留忠实原图并如实说明编辑边界。生成图不绘中文、坐标或整页 PPT。
- 按 [证据与科学图](references/evidence-and-diagrams.md) 保留变量、单位、基期、比较时期、不确定性与来源时代。真实感插画从不充当新证据。
- 只有当前任务明确选择页脚简化时，来源和生成示意身份才迁移到备注/来源页；否则正常可读地呈现。必要的正常字号“机制示意”、条件和误读防线仍留在画面。不要用微小页脚替代可读限定，也不要无痕伪装为实测。

## 6. 检查最终文件再交付

按 [验收与交付](references/review-and-delivery.md) 先用困难代表页校准，再落实全稿。已认可方向就继续制作，不反复要求用户确认同一选择。

最终 PPTX 全页渲染，逐页检查科学语义、实体与标签、正常阅读距离及原生对象；再看全稿节奏，排除机械复用的面板骨架。只查无越界不够，指向河流的“降水”标签即使对齐仍错。

scripts/check_pptx.py 只读检查结构、媒体占用及用户显式预算，默认无上限；不能证明美观、科学正确或可编辑体验。交付实际范围、对应预览和真实验证方式。不打包外部版权参考图、整本书、私有制作记录或无关资料。
