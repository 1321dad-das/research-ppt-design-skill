# 科研 PPT 设计 skill · v6

从研究材料组织来源可追溯的视觉故事：根据空间、过程、因果或比较关系选择布局，让大场景、原生图解与真实证据各司其职。缺少有助于理解的非定量科学插画时主动生成，不用装饰缩略图代替重构，也不生成假数据。

## 使用

让支持文件式 skill 的助手读取 SKILL.md，并提供研究材料、目标范围、参考图和最新要求；也可作为制作规格交给制作者。无需特定私有工具或账号。图像生成、渲染和编辑需要当前环境提供相应能力，技能包本身不附带这些服务。

任务示例：

“依据这些研究材料做成来源清楚、像 NotebookLM 一样容易理解的科研 PPT。保留皇家蓝、白底、少量红色和科研信息密度。按每页关系决定构图，缺少解释性的科学插画就生成，主图要真正讲清对象和过程，不要每页三卡片或顶部小配图。普通主题标题也可以。真实图表、条件和表格要准确，文字、标签、箭头可编辑。”

样式档案例子：皇家蓝/白底/少量红色、科研高密度、原生文字与过程标注。这是可选风格，不适用于所有任务。若当前任务明确要求去掉内容页小来源/生成说明，则迁移完整记录到逐页备注和可读的末尾来源页；否则使用正常可读的来源呈现。页码、重要科学限定及许可要求的署名不能因此删除。

默认无文件大小上限，只有当前任务明确要求时才设置预算。样式示例不代表历史偏好、素材使用授权或外部研究范围。

## 文件与检查

本包包含入口、按需参考和只读 PPTX 检查脚本。脚本仅需 Python 3 标准库；--max-bytes 仅用于当前明确指定的预算。结构检查不代替实际渲染、科学核对或应用中的编辑测试。

本包不含书籍、外部参考图片、字体、研究结果或完整 PPT。示例是条件性的制作方法，不是对具体研究事实的断言。v6 独立保存，不覆盖 v5，也不声称整套成稿或所有软件已通过验收。
