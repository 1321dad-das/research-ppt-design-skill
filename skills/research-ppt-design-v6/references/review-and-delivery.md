# 验收与交付：科学语义、审美结构与实际文件

## 五项分别检查

1. 科学准确：变量、单位、基准、来源、限定与因果关系正确。
2. 参考匹配：蓝白结构、真实感对象、原生过程标签、密度和红词角色符合用户当前方向。
3. 场景有效：图片真正解释空间/过程，不是装饰；实体、物理接口与标签锚点相符。
4. 正常阅读：关键图文在实际尺寸和合理观看距离可读，不仅无重叠或截断。
5. 文件实现：最终 PPTX 可打开，页数和顺序正确，必要对象可编辑，预览来自同一版本。

不以“顶级审美”自评放行，用这些可观察条件逐项检查。代表页已完成或获认可不等于全稿完成。

## 来源与叙事检查

在逐页画面检查之外，还要看完整顺序：

- 每页讲述任务明确，前后承接自然；并非按原文段落机械排卡片。
- 命题能回到实际来源，合并多来源后没有误造共同基期、对象或结论。
- 背景/方法页允许主题标题；结论标题有相应证据，不压掉条件或放大因果。
- 构图反映空间、过程、比较或定量关系；必要对照之外，没有不顾内容的重复面板骨架。
- 新增图片真正承担解释，足够大且与文字重组；不是旧正文加装饰缩略图。若摘要框、过渡横带、面板标题和底部结论都在重复同一意思，优先合并这些外框，让实际关系成为主体。不要为改变而拆掉已经清楚的真实证据页或精确表格。
- 缺失解释插画已补足并核查，缺失真实证据仍被如实标记；两者没有混淆。

## 合成页面逐页检查

从将要交付的最终 PPTX 导出所有页面，而不是只看孤立素材或生成器截图。记录每页问题、修复和未决项：

- 命题、对象、过程与证据对应；照片/场景没有替换必须保留的实测结果或表格。
- 图片若移走，是否失去其承担的解释？若没有，应考虑重构而非继续加装饰。
- 标签与引线落在正确实体；雨线不是河流，气柱不是深海，闸门不是随便一片湖面。
- 水面水平、河流连接、根系依附、设备位置和接口合理；没有碎片、裁切残影或隐蔽白边。
- 镜头、光照、材质和比例与相邻场景连贯。合理示意不同于任意失真；必要尺度边界明确。
- 过程箭头方向有依据；位置/面积/线宽没有无意冒充数值；没有伪热图、虚构曲线或假技能对比。
- 图表坐标、图例、色标、单位、基期、时期、样本/集合信息与不确定性完整且读得出。
- 原文的关键定义、数字、假设和边界还在；未把全文照旧缩小后附一张图，也未为了简洁删掉科学条件。
- 字体、中文、上下标、希腊字母与负号正确；无漏显、拉伸、遮挡、越界。XML 含文字不等于画面已显示。
- 文字、表格、标签和关系线可编辑，真实证据原图的图片属性被如实说明。

修改图像、字体、压缩或布局后重查相关页；结构性修改后重看全稿。只有要求修复而未查看修复结果，不能写“问题已解决”。

## 正常阅读距离

先全页正常显示，检查标题、对象、主关系与关键条件；再放大看细节；最后看全稿缩略图的连贯性。只在放大下检查，会漏掉“图很精细但读不懂”的问题。

字号是起点，不是通过证据。图内细字、颜色对比或图像缩小导致难读时，重分空间、减冗余或调整分组，不继续缩字体。目标设备可用时实际测试；不可用时如实说明验证方式。

## 用户选择的页脚简化模式

仅在当前任务明确选择去掉底部小来源/生成说明时使用。未作此选择时，按任务规范或正常可读的方式呈现来源，不能从历史版本或本包示例推定选择：

- 从内容页画布移除这类微小页脚，保留原生页码。不把已经删除的小字换一个位置重新偷偷塞回。
- 每页演讲者备注保留完整来源：作者/年份、书或文章、章节/图号/页码、链接/DOI、图件处理和替换情况。生成场景记录用途与“非观测、非定量模型结果”等适用说明。
- 最后来源页提供可读的书目/链接及页面或图件映射，不只写一个笼统作者名。不能把整页重复微缩脚注堆到最后来形式上完成。
- 数值图原有坐标、轴、图例、色标、单位、条件不属于要删的页脚。影响理解的基期、比较期、概念性、时代范围与不确定性继续正常字号可见。
- 概念场景必要时在组头或逻辑带写“机制示意”。完整说明可移备注，但不能使画面误导为实测或实际地点。
- 素材许可若要求画面署名，应保留合规署名或更换素材，不能用版式选择绕过要求。

这是经过明确选择后的来源位置调整，不是不引用来源。未明确选择时，不自动移除画布来源；当前任务另有规范则按其执行。检查备注时实际读取最终 PPTX 的对应备注内容；仅创建了 notes 文件/空备注部件不算保留。

若另交纯图或 PDF，演讲者备注可能不随格式输出。把来源索引保留在末页或可访问的配套来源文档，且画面保留足以避免误读的重要限定。不能声称所有格式都保留了 PowerPoint 备注。

## 手机预览

从最终版渲染提供代表性单页图，允许点开放大；全稿联系表只用于扫读，不是唯一入口。长图过密则分组并标页码。在约 390–430 px 宽视图检查标题、对象和总体关系可辨，密集科学图的细节可依赖单页放大，不承诺缩略图下全部脚注可读。

## 体积与只读脚本

默认无任何大小上限。清理重复媒体、无用背景和不必要嵌入物；按实际显示尺寸合理压缩，保留源材料。只有用户当前明确指定时才设预算，不要从旧版本沿用当前任务没有要求的限制。

    python scripts/check_pptx.py my-deck.pptx
    python scripts/check_pptx.py my-deck.pptx --json

用户明确指定预算时才使用，例如：

    python scripts/check_pptx.py my-deck.pptx --max-bytes 20000000

退出码 0 仅表示脚本未发现结构/预算阻断；1 表示关系、文件、无幻灯片或超出显式预算；2 表示参数/读取错误。脚本不验证画面、锚点、来源充分性、科学、阅读距离或真实编辑体验。

## 诚实交付

说明完成范围、主要修改、对应预览、编辑范围和实际检查方式。没有检查目标应用时不声称该应用通过；不承诺 Windows 或所有设备无差异。

技能包和部分样页不代表整套成稿已经验收。不要附带外部版权参考图、整本书、私有工作记录或无关数据。
